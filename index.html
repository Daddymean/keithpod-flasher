Flash Keithpod

Install Keithpod on the Waveshare ESP32-S3-Touch-AMOLED-2.06 watch. Use desktop Chrome or Edge (Web Serial). A USB-C data cable is required.

  1. Plug the watch in with USB-C.
  2. Click Connect, pick the watch's port, then Install.
  3. If no port appears, hold BOOT, tap PWR, release BOOT, then Connect again.
  4. When Chrome asks for Wi-Fi, enter your home 2.4 GHz network. Leave the server URL unset for now.
  5. If that dialog does not appear, join the open Wi-Fi Keithpod-setup on your phone, open http://192.168.4.1, and enter Wi-Fi there. Copy the device secret shown on that page.

First flash: erasing is fine. Do not erase when updating, or the watch forgets Wi-Fi and the device secret, and clips already on the card can no longer be decrypted.

After flashing, a FAT32 microSD card (32 GB or smaller is simplest) lets the watch save clips until a server is set up. Serial logs are at 115200 baud if anything looks wrong.

This page is static, costs nothing, and stores no secrets. Firmware source and longer notes live with the keithpod firmware tree (FIRMWARE.md).
